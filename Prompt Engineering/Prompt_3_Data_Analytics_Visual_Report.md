## Prompt Used

```
Upload a raw, unorganized regional development dataset into an advanced AI data-analysis environment, clean the database structurally, and generate a pair of high-contrast visual trend charts accompanied by a human analytical narrative.

Role: You are a Data Analyst attached to a regional development council or environmental monitoring coalition in Mindanao.

Audience: Regional Policymakers and LGU Department Heads who need clear, unbloated data visualizations to allocate budgetary resources effectively.

Situation: Your department received a disorganized CSV file documenting regional economic trends. You have less than an hour to isolate key metrics, clean out formatting corruptions, and produce highly readable data visualizations for an emergency legislative session.

Focus the dataset on local renewable energy output (Solar vs. Hydro) across Davao Region provinces, 2019-2023. The raw CSV should contain mixed units (MW vs kW) and missing values that need cleaning.

Produce an Automated Visual Data Report formatted as a GitHub README.md, containing:
1. A Data Cleaning Protocol Log: describe the raw input problem, the exact AI cleaning instruction used (as a quoted command), and the cleaning result (rows normalized, clusters handled)
2. Two embedded analytical data charts: a line chart and a bar chart, generated from the cleaned dataset
3. A human-authored analytical narrative (the "Why" Factor) that challenges or adds nuance to what the automated AI summary concluded, tying the data to a specific socio-environmental reality in Mindanao and a policy recommendation

Match this exact structure and tone:
### Data Analytics & Visual Report
#### Dataset Focus: [Region] [Topic] Index (Mock CSV Analysis)
#### 1. Data Cleaning Protocol Log
#### 2. Visualizations Generated
#### 3. Human Analytical Narrative (The 'Why' Factor)
```
